# Changelog

## 0.1.0

- Interstitial, rewarded and banner ads from Unity LevelPlay 9.8.0 with Unity Ads 4.22.0 (adapter 5.17.0), for Godot 4.7 on Android.
- Banners in five sizes, centred at the top or the bottom of the screen with a margin.
- Consent setters for GDPR, US privacy and child-directed treatment.
- Test mode that serves LevelPlay's public demo app instead of your own, and LevelPlay's integration test suite in debug builds and test mode.
- `app_left` for full-screen ads covered by something outside the app, Play's install overlay included, and an opt-in `ad_overlong` for ads that stay up too long.
- The network that filled each full-screen ad, in `ad_shown`.
- Every Unity version pinned, including the two Unity asks for by a range.
